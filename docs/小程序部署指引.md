### 5.2 微信对后端的硬性要求

- 请求必须走 **HTTPS**（TLS ≥ 1.2），自签名证书不行；
- 域名必须**已完成 ICP 备案**，备案主体与小程序主体一致或关联；
- 域名配到后台「开发管理 → 开发设置 → 服务器域名」的 **request 合法域名**（每类上限 20 个）；
- **不支持 IP 和端口号**，代码里请求的域名必须与后台配置**完全一致**（含二级域名）；
- 开发/体验版可开「调试模式」跳过校验，**正式版不行**。

### 5.3 写接口访问控制（✅ 已于 2026-09-30 实现）

**背景**：`/api/manage/*`（改封面/介绍/别名）、`/api/jobs/*`（触发全库重采）、
`/api/settings/llm`（改写 LLM 配置）、`/api/llm/*` 与 `POST /api/memes/{id}/insight`
（消耗 LLM 额度）原本**没有任何校验**，公网暴露 = 任何人都能改数据、烧额度。

**已实现的方案**：`ADMIN_TOKEN` 环境变量 + 请求头 `X-Admin-Token`。

| 情形 | 行为 |
| --- | --- |
| `ADMIN_TOKEN` **留空**（默认） | 写接口**放行** —— 本机/内网开发体验完全不变，且不会"一上线就 401" |
| `ADMIN_TOKEN` 已设置 | 写接口必须带 `X-Admin-Token: <值>`，缺失或错误 → **401** |

- 守卫挂在 `app/api/__init__.py` 的 router 层（新增写接口默认受保护，不易漏挂），
  `POST /api/memes/{id}/insight` 因与只读接口同路由，在 `memes.py` 内单挂；
- 比较用 `secrets.compare_digest`（定长比较，不泄漏令牌长度/前缀）；
- **只读接口永远公开**：`/api/health`、`/api/meta`、`GET /api/memes*`。
  小程序端只走这几个，因此**开不开令牌，小程序都能正常用**；
- 覆盖用例：`backend/tests/test_admin_guard.py`（含"挂漏路由"的回归防护）。

**上线前必做**：在 `backend/.env` 里设置 `ADMIN_TOKEN`，生成方式：

```bash
python -c "import secrets;print(secrets.token_urlsafe(32))"
```

**已知限制（需你决策）**：Web 前端的管理页（`/manage`）与 AI 卡片目前**不会带该请求头**。
开启令牌后这些页面会收到 401。三个选项：

1. 管理功能**只在局域网访问后端**，公网只暴露只读接口（最省事，推荐）；
2. 给前端补一个「令牌」输入框，存 `localStorage` 并在请求头里带上（需改前端）；
3. 写接口继续放在独立的、不对外暴露的端口/内网地址上。

### 5.5 阿里云专属清单（已有域名后，还缺什么）

**域名只是三件套之一**：域名 + 已备案 + 服务端（含 HTTPS）。

#### ⓪ 当前实测状态（2026-09-30 15:45 本机核实）

| 项 | 实测结果 |
| --- | --- |
| 域名 | `luckyzyb.top` |
| ICP 备案 | ✅ 已完成，**个人主体**（在阿里云） |
| 阿里云云产品 | ❌ **已无服务器** |
| DNS 解析 | ⚠️ **全部指向 Cloudflare**：`104.21.7.34` / `172.67.135.176`；NS 为 `jessica.ns.cloudflare.com` / `roan.ns.cloudflare.com` |

**由此暴露两个必须先处理的问题——都属于「已有资产正在失效」：**

**红牌 1 —— 无服务器，备案接入悬空。**
阿里云帮助中心原文：备案过程中或备案完成后，若关联服务器到期释放，
「**该备案号可能会被注销**」（[轻量应用服务器 FAQ](https://intl.aliyun.com/help/zh/doc-detail/60082.htm)）。
备案一旦被注销就要从零重走（再等 7–20 工作日）。**这是当前最大的时间风险。**

**红牌 2 —— 域名解析在境外 Cloudflare，与备案的「接入」信息冲突。**
ICP 备案登记的接入商是**境内 IDC**；域名长期解析到境外 IP、账号下又无云产品，
核查时会判定接入信息不实，先「**取消接入**」、进而可能「**注销备案**」。
另有资料称微信侧也会核查解析 IP 是否在境内（此点**我未找到微信官方明文条款**，
但它属于管局备案核查的常规项，且与你的接入信息直接相关，建议按「必须切回境内」处理）。

> **顺序：先把域名解析切回阿里云境内服务器，再谈微信后台配置。**
> 顺序反了会白做——备案被注销时，后台连域名都填不进去。

#### ① 先确认域名的四个状态（最容易踩）

| 检查项 | 不满足的后果 |
| --- | --- |
| **已实名认证** | 未实名的域名**不能备案**；且**实名信息必须与备案主体负责人一致**，否则管局直接驳回 |
| **备案是否仍有效** | 「已在阿里云备案」≠「永久有效」：**无云产品 / 解析不在境内**都会被核查撤销（见 ⓪） |
| **后缀可否备案** | `.com / .cn / .net` 审核最顺畅；`.top / .xyz` 部分省份管局审核更严。你的 `.top` **备案已通过**，合规层面没问题（但见下方提醒） |
| **备案主体是谁** | 必须与**小程序主体一致**（个人小程序 → 个人名义备案）。你的是**个人**，则小程序主体也须是个人，否则微信侧会拦 |

> 域名**已备案过**的无需重新购买，走「**新增接入**」把它接入当前服务器即可；
> 从未备案的走「首次备案」。备案期间**域名不能开放访问**（未备案域名解析到
> 阿里云中国内地服务器会被监测系统识别并阻断）。

> ⚠️ **`.top` 的额外风险（风险提示，非硬门槛）**：腾讯云开发者社区的风控说明把
> `.top / .xyz` 归为「特殊域名后缀」，微信风控审核更严格、更易触发链接拦截；
> 微信开放社区也有 `.top` 域名被拦截后走申诉恢复的案例帖。
> 已备案的 `.top` **可以**正常填进服务器域名列表，但要有「偶发拦截、需申诉」的预期。
> 要彻底规避只能换成 `.com / .cn` 并重新备案。

#### ⓪-b 别漏了「小程序专项备案」（与域名备案是两件事）

`luckyzyb.top` 的备案是**域名 ICP 备案**，它**不能替代**小程序本身的备案。
「小程序专项备案」2023-09 起对所有小程序强制，入口在
**微信公众平台 → 设置 → 基本设置 → 小程序备案**，绑的是**小程序主体**，免费。

若你此前只做了阿里云的域名备案，这一步**还没做**，需补上（7–20 工作日，可与服务器采购并行）。

#### ② 服务器：唯一要花钱的项，但在校生可压到 ≈0 元

按阿里云官方要求（[备案服务器检查](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/host-instances-and-service-providers)），

- **支持**：ECS / 轻量应用服务器 / 云虚拟主机；
- **包年包月**，且**购买时长 > 3 个月**（含续费累计，与剩余期限无关）；
- ECS 还需**购买公网带宽**；
- ⚠️ **免费试用的 ECS 不满足**备案要求；按量付费须转为包年包月；
- ⚠️ **SLB / ACK 容器服务不算**可备案云产品，需另备一台符合条件的 ECS。

> 本项目后端是 FastAPI，**不能用云虚拟主机**（那类只适合静态页 / PHP），
> 需要 **ECS 或轻量应用服务器**。

#### ④ 微信后台配置（保存后 5–15 分钟生效）

```
https://api.你的域名.com
```

#### ⑤ 后端要做的改造

现在后端是 `http://` + `:8010` + 局域网，上线前至少要：

1. 部署到 ECS / 轻量，用 **Nginx（或 Caddy）反代**到 uvicorn，对外只开 **443**；
2. 域名 **A 记录**解析到服务器公网 IP ——
   ⚠️ **不要走 Cloudflare 橙云代理**，否则对外解析仍是境外 IP，备案接入问题原样存在。
   若坚持用 Cloudflare 做 DNS，必须设为「**灰云 / DNS only**」；
   最省事的做法是把解析搬回**阿里云云解析**（NS 一并改回，注意 24–48 小时生效）；
3. 安装证书并启用 TLS ≥ 1.2；
4. 在 `backend/.env` 里**设置 `ADMIN_TOKEN`**（见 §5.3）——公网部署**必须开**；
5. 备案审核期间保持域名不可访问，备案通过后再开放；
6. 小程序端把 `miniprogram/src/api/client.ts` 的默认 `BASE_URL`
   从 `http://127.0.0.1:8010` 改为 `https://luckyzyb.top`，
   并把 `project.config.json` 的 `urlCheck` 改回 `true`（本地调试才关它）。

#### ⑥ 别忘了个人主体的类目红线

个人主体**不能做「信息资讯 / 新闻」类目**，且**禁止 UGC**（评论、留言、用户发帖）。
「赶梗潮」是内容聚合型，提审时要往 **「工具 - 查询（仅展示）」** 方向表述，
**不能写成资讯平台**，否则代码审核必被驳回——这个坑比花钱更容易踩。

## 六、安全提醒（真机预览期间）

改绑 `0.0.0.0` 后，**局域网内任何设备都能访问全部接口**。动手前请先做一件事：

**在 `backend/.env` 里设置 `ADMIN_TOKEN`**（生成方式见 §5.3）。设置之后，
`/api/manage/*`、`/api/jobs/*`、`/api/settings/llm`、`/api/llm/*`、
`POST /api/memes/{id}/insight` 都要求请求头 `X-Admin-Token`，不合规直接 **401**；
而小程序端**只走公开的只读接口**，因此**不受影响，照常可用**。

> 留空（默认）时写接口是放行的。在自家可信局域网里做一次预览可以接受，
> 但**不要**在咖啡厅、共享办公等不可信网络下这么干。
> 注意：开了令牌后，Web 前端的 `/manage` 页与 AI 卡片会 401（它们不带该请求头），
> 处理选项见 §5.3。

- 只在**可信 WiFi** 下做真机预览；
- **预览结束就停掉后端**（或改回 `127.0.0.1`），不要长期挂在 `0.0.0.0`；
- 更小的暴露面：只放行手机那一个 IP（需管理员权限新建防火墙规则）。
